# Interactive Sound Map

## Описание
Интерактивная карта звуков, позволяющая исследовать различные звуковые сценарии в зависимости от местоположения и условий.

## Функциональность
- **Фильтрация по типу звука** (Ambient Noise, City Traffic, Forest Sounds).
- **Адаптивный интерфейс** для разных устройств (десктоп, лэптоп, мобильное).
- **Анимации загрузки и взаимодействия** для улучшения пользовательского опыта.

## Как пользоваться
1. Откройте страницу в браузере.
2. Используйте кнопку "Filter by Noise" для выбора типа звука.
3. Прокрутите страницу вниз для просмотра карточек с описаниями.

## Технические требования
- Современный браузер (Chrome, Firefox, Safari, Edge).
- Поддержка CSS Grid и JavaScript.
