# Interactive Sound Map

## Описание
Проект интерактивной карты звуков с адаптивным интерфейсом и анимациями.

## Итоговые улучшения

### 🔧 Технические исправления
1. **Анимации:**
   - Добавлены плавные анимации для карточек (`opacity`, `transform`).
   - Исправлены залипания фонов и эффекты `:hover`, `:active`.

2. **Адаптивность:**
   - Карточки адаптируются к ширине экрана на всех устройствах.
   - Отступы и выравнивание корректируются для мобильных устройств.

3. **Контрастность:**
   - Все текстовые элементы соответствуют WCAG (минимум 4.5:1).
   - Темный/светлый режимы с переключателем и `prefers-color-scheme`.

4. **Доступность:**
   - Добавлены ARIA-атрибуты и микровзаимодействия (`:hover`, `:active`).

### 📱 Тестирование
- **UI Audit:** Проверка адаптивности на всех устройствах (десктоп, планшет, мобильный).
- **Производительность:** Оптимизация анимаций и рендеринга.
- **Контрастность:** Проверка с помощью инструментов WCAG.
